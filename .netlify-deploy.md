# Deploying Color My Life to Netlify

## Prerequisites

1. **Netlify Account**: Sign up at https://netlify.com
2. **PostgreSQL Database**: Set up a production database (recommended: Neon, Supabase, or Railway)
3. **Cloudinary Account**: For product image uploads (sign up at https://cloudinary.com)
4. **Resend Account**: For password reset emails (sign up at https://resend.com)

## Step 1: Install Netlify CLI

```bash
npm install -g netlify-cli
```

## Step 2: Login to Netlify

```bash
netlify login
```

## Step 3: Initialize Netlify Site

From the project root (`e:\Cilent project\Miniature`):

```bash
netlify init
```

Follow the prompts:
- Create & configure a new site
- Choose your team
- Site name: `color-my-life` (or your preferred name)
- Build command: `npm run build`
- Publish directory: `.next`

## Step 4: Set Environment Variables

You need to configure these environment variables in Netlify:

### Required Variables:

```bash
# Database (use your production PostgreSQL URL)
netlify env:set DATABASE_URL "postgres://USER:PASSWORD@HOST:5432/DATABASE?sslmode=require"

# Auth (generate with: npx auth secret)
netlify env:set AUTH_SECRET "your-generated-secret-here"

# Site URL
netlify env:set SITE_URL "https://your-site-name.netlify.app"

# Admin account
netlify env:set ADMIN_EMAIL "emon.artist.yt@gmail.com"
netlify env:set ADMIN_PASSWORD "your-secure-password"

# Cloudinary (from your Cloudinary dashboard)
netlify env:set CLOUDINARY_CLOUD_NAME "your-cloud-name"
netlify env:set CLOUDINARY_API_KEY "your-api-key"
netlify env:set CLOUDINARY_API_SECRET "your-api-secret"

# Resend (from your Resend dashboard)
netlify env:set RESEND_API_KEY "your-resend-api-key"
netlify env:set EMAIL_FROM "Color My Life <no-reply@colormylifebd.com>"
```

### Alternative: Set via Netlify Dashboard

1. Go to your site settings on Netlify
2. Navigate to **Site settings** → **Environment variables**
3. Add each variable manually

## Step 5: Run Database Migrations

After setting up your production database, run migrations:

```bash
# Set DATABASE_URL in your local .env to point to production database
npm run db:deploy
```

Then seed the database:

```bash
npm run db:seed
```

## Step 6: Deploy

```bash
netlify deploy --prod
```

Or push to your Git repository and Netlify will auto-deploy.

## Step 7: Configure Custom Domain (Optional)

If you want to use `colormylifebd.com`:

1. Go to **Site settings** → **Domain management**
2. Add custom domain: `colormylifebd.com`
3. Follow Netlify's DNS configuration instructions
4. Update `SITE_URL` environment variable to `https://colormylifebd.com`

## Troubleshooting

### Build Errors

If you get Prisma errors during build:
- Ensure `DATABASE_URL` is set correctly
- The database must be accessible from Netlify's build servers
- Prisma generates the client during `postinstall` script

### Image Upload Issues

- Verify Cloudinary credentials are correct
- Check that `CLOUDINARY_CLOUD_NAME` matches your Cloudinary account
- Test uploads in production after deployment

### Email Issues

- Verify domain in Resend dashboard
- `EMAIL_FROM` must use a verified domain
- Check Resend API key is valid

## Monitoring

After deployment, monitor your site:
- Netlify Dashboard: Build logs and function logs
- Database: Check connection and query performance
- Cloudinary: Monitor storage and bandwidth usage
- Resend: Check email delivery status

## Quick Deploy Command

Once configured, you can deploy with:

```bash
netlify deploy --prod
```

Or set up automatic deployments from Git:
1. Link your repository in Netlify dashboard
2. Every push to `main` branch will auto-deploy
